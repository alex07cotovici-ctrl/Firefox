# Firefox start page

A custom new-tab page: time-of-day forest scene, dock of shortcuts (with your own photos as icons), smart search with `!bangs`, focus timer with ambient sounds, medical term of the day and a countdown.

**Use it as your Firefox new tab:** enable GitHub Pages for this repo (Settings → Pages → Deploy from branch `main`, folder `/`), then point the "New Tab Override" add-on at the Pages URL.

Shortcuts: `/` focus search · `1`–`9` open shortcuts · `Space` start/pause timer.
